# nDOS controls

Language for the controls used to operate nDOS while running DOS software.

## Language

**Landscape toolbar**:
The strip of nDOS controls available along an edge of the screen in landscape orientation.
_Avoid_: Landbar, fullscreen panel

**Pinned toolbar**:
A landscape toolbar that stays visible instead of automatically hiding. Unpinning returns it to the user's last timed auto-hide choice.
_Avoid_: Sticky toolbar

**nDOS-X**:
The experimental nDOS app used to evaluate DOSBox-X for running DOS software and Windows 95/98.
