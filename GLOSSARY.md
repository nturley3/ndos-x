# nDOS controls

Language for the controls used to operate nDOS while running DOS software.

## Language

**Landscape toolbar**:
The row of nDOS controls available along an edge of the screen in landscape orientation.
_Avoid_: Landbar, fullscreen panel

**Collapsed toolbar**:
A landscape toolbar showing only its expand arrow. Controls return when expanded, and may collapse automatically after the chosen delay.
_Avoid_: Hidden toolbar, pinned toolbar, sticky toolbar

**nDOS-X**:
The experimental nDOS app used to evaluate DOSBox-X for running DOS software and Windows 95/98.
