# nDOS language

Language for operating nDOS and its virtual machine while running DOS software.

## Language

**Landscape toolbar**:
The row of nDOS controls available along an edge of the screen in landscape orientation.
_Avoid_: Landbar, fullscreen panel

**Collapsed toolbar**:
A landscape toolbar showing only its expand arrow. Controls return when expanded, and may collapse automatically after the chosen delay.
_Avoid_: Hidden toolbar, pinned toolbar, sticky toolbar

**nDOS-X**:
The experimental nDOS app used to evaluate DOSBox-X for running DOS software and Windows 95/98.

**CD-ROM drive**:
The virtual optical drive visible to DOS or Windows. It can contain a disc image or have an empty tray.
_Avoid_: ISO drive

**Disc image**:
A file representing a CD’s contents, inserted into a CD-ROM drive. Changing the disc image leaves the drive itself in place.
_Avoid_: CD-ROM drive, disk image when referring specifically to a CD

**Eject disc**:
Remove the disc image from a CD-ROM drive while leaving the drive available with an empty tray. Another disc image can be inserted into the same drive later.
_Avoid_: Unmount drive, remove drive
